# Screenshots

Drop the assets the main `README.md` references in this directory:

- `pilots.png` — the Pilot Roster view with 2–3 cards visible, ideally one
  Launched (Online status badge lit). 1200–1600 px wide; PNG.
- `settings.png` (optional) — the System Configuration view scrolled to the
  EVE Vault Integration section. Useful in a future "Installers" doc.
- `pilot-card.png` (optional) — a single pilot card close-up. Good
  for the "What" section.

Keep the same window chrome (Bifrost frame + accent corner brackets)
across screenshots so the visual identity is consistent.

If you record a GIF demonstrating "launch pilot → coloured Brave window
appears", drop it here as `launch-demo.gif` (≤ 8 MB so GitHub inlines
it without a load-on-click placeholder).
